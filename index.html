5 압수서류작성 0 / 5
5-1 압수조서 (편철)
  • 압수물 › 압수물목록 › (대상 압수물 체크박스 체크) › 압수관련서식(드롭다운) › 압수조서(클릭) › 열기
  • (압수경위 등 기본정보 입력)
  • (상단) 진술자 확인(클릭) › (팝업창 상대방 열람)
  • (참여인 서명 또는 날인으로 커서이동) 자필기재(클릭)
  • (서명패드) 서명 › 확인
  • 사법경찰관(리) 입력 (서식의 명의자 및 참여 경찰관)
  • 서식의 명의자 및 참여경찰관(추가명의자)의 행정전자서명 필요
  • 편철
  • 행정전자서명관리 › (추가명의자) › 추가
  • (PDF 변환) 확인 › (성공) 확인
5-2 압수목록 (편철)
  • 압수물 › 압수물목록 › (대상 압수물 체크박스 체크) › 압수관련서식(드롭다운) › 압수목록(클릭) › 열기
  • 편철 › 확인 › 확인 › (PDF 변환) 확인 › 확인(성공)
5-3 압수목록교부 (결재올림)
  • 압수물 › 압수물목록 › (대상 압수물 체크박스 체크) › 압수관련서식(드롭다운) › 압수목록 교부(클릭) › 열기
  • (압수목록교부서 내용입력)
  • 결재올림 › 결재선지정(팀장) › 확인
5-4 임의제출 (편철)
  • 압수물 › 압수물목록 › (대상 압수물 체크박스 체크) › 압수관련서식(드롭다운) › 임의제출(클릭) › 열기
  • (상단) 진술자 확인 › (팝업창 상대방 열람)
  • (제출자 인 란으로 커서이동)
  • (상단) 자필기재(클릭) › (서명) › 확인
  • (제출자 처분의견 란으로 커서이동)
  • (상단) 자필기재 › (소유권포기 등 기재) › 확인
  • 소유권 포기를 기재한 경우, 소유권포기서 별도 작성 불필요
  • (상단) 편철 › (PDF 변환) › 확인
5-5 행정전자서명
  • KICS › 사건처리 › 접수배당 › 사건목록 › 지역경찰사건목록
  • (대상사건 우클릭) › 서식
  • 작성문서(해당문서 클릭) › 행정전자서명 › 확인
  • (인증서 선택창) › 사용할 인증서 선택 › 비밀번호 입력 › 확인
